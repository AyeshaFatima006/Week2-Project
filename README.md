# Travel Website - Project 2

A basic backend server built with Node.js and Express.

## Requirements

- Node.js and npm

## Install dependencies

From the `project2` folder, run:

```powershell
npm install
```

If PowerShell blocks `npm`, use:

```powershell
npm.cmd install
```

## Run the server

From the `project2` folder, run:

```powershell
node .\server.js
```

The server runs on port 3000. Open [http://localhost:3000](http://localhost:3000) in a browser. The `/` route responds with:

```text
Welcome to the Travel Website backend!
```

Press `Ctrl+C` in the terminal to stop the server.
